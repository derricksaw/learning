01 / Intuition & Workload Fit

Start from the access pattern, not the protocol URL

Local POSIX block filesystems, shared NAS shares, and object stores solve fundamentally different concurrency and mutability problems. Choose based on whether workloads need in-place byte edits and POSIX locks, shared multi-host trees, or HTTP-addressed immutable blobs.

Architectural Boundary — Hybrid File Gateways & FUSE

What works and what breaks when putting NFS/SMB in front of Object Storage

Hybrid architectures often pair AWS DataSync (bulk transfer up to 10 Gbps, preserving POSIX UID/GID/timestamps as S3 object metadata) with an on-premises File Gateway (VMware ESXi, Hyper-V, KVM, or hardware appliance with up to 64 TB local cache and TLS encryption to S3). Because files and objects behave differently, gateway and FUSE layers fit specific access patterns only.

What Works Well
  • Write-once, read-many data: media, images, scientific datasets, and documents read sequentially.
  • Ingest landing zones & archives: cameras, instruments, or backup shares dropping immutable files.
  • Cached user file shares: File Gateway acknowledges writes to local cache immediately, uploads asynchronously to S3, and syncs via the automated cache-refresh timer (e.g., 30-minute duration-since-last-access) or RefreshCache API.
What Breaks
  • In-place updates & line-by-line appends: databases, VM images, or live logs force full-object rewrites on object storage.
  • Heavy small-file metadata activity: software builds and source trees incur per-object HTTP latency on every stat, create, or delete.
  • Large directory renames & strict locks: renaming a simulated prefix copies and deletes every object beneath it; S3 clients ignore file locks unless coordinated by a gateway.

Flat Key Namespace vs. Virtual Folder Illusion

  • Zero native directories: Renaming a folder means copying and deleting every object sharing that prefix.
  • High-concurrency keys: Use generated UUID keys (e.g., quarantine/{userId}/{uuid}) to prevent hotspots and eliminate filename collisions.
  • Lifecycle & Immutability: Pair S3 Versioning + Object Lock (WORM) with Lifecycle rules to tier cold objects and abort incomplete multipart uploads.
03 / Production Architecture

Decouple the control plane from the data plane

Funneling large user uploads through application servers exhausts memory, connections, and CPU. Production systems authorize uploads in the API control plane, offload raw byte transfers directly to OSS via short-lived presigned URLs, and validate asynchronously.
